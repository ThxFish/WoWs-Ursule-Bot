# 机器人消息格式

| 发送的信息                         | 返回的信息                 |
| ---------------------------------- | -------------------------- |
| /帮助 或者 /help                   | 返回所有指令功能           |
| /活动 或者 /event                  | 返回活动图片, 展现当前状态 |
| /新闻 或者 /news                   | 返回消息图片               |
| /我 或者 /me                       | 返回战绩图片               |
| /近期 或者 /recent 参数            | 同原指令/wws me recent参数 |
| /随机 参数 或者 /random 参数       | 同原指令/近期随机战绩 参数 |
| /排位 参数 或者 /rank 参数         | 同原指令/近期排位战绩 参数 |
| /单船 船名参数 或者 /ship 船名参数 | 同原指令/单船数据查询 参数 |
| /类别 参数 或者 /category 参数     | 同原指令/筛选船只数据 参数 |
| /日报 或者 /daily                  | 发送日报图片               |
