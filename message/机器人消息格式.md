# 机器人消息格式

## 节日船团

| 发送的信息     | 返回的信息                                   |
| -------------- | -------------------------------------------- |
| /节日船团 进度 | 返回当日代币、总目标和当前缺口               |
| /节日船团 资源 | 返回煤炭、钢铁、研发点和加成卡数量信息       |
| /节日船团 爬线 | 返回当前舰船、完成轮数和下一个目标的截止日期 |
| /节日船团 同步 | 立即采集数据并返回结果（成功/失败及其原因）  |
| /节日船团 帮助 | 显示可用命令                                 |
