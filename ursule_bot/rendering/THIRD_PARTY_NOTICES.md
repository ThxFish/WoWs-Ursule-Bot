# Third-party rendering assets

The files under `assets/kokomi/` are adapted from
[`SangonomiyaKoko/Kokomi_Bot`](https://github.com/SangonomiyaKoko/Kokomi_Bot),
revision `c7501d3`, and retain the original Kokomi Bot card dimensions and visual
layout. The upstream project is licensed under CC BY-NC 4.0. These assets are
included for attribution-required, non-commercial use only.

Personal Rating uses the formula and per-ship expected values published by
[`WoWS Numbers`](https://wows-numbers.com/personal/rating), as required by that
data provider's attribution terms. The downloaded table is stored at runtime
under `data/ships/expected_pr.json`; it contains ship reference values and no
player records.
